# Offline AI Companion

A Python-first, offline AI companion designed to communicate naturally, maintain a consistent character, remember useful information, and eventually work as a local code/file agent.

## Status

Phase 1 — architecture and requirements defined.

See [`PHASE_01.md`](PHASE_01.md) for the current architecture, requirements, decisions, and roadmap.

## Principles

- Offline-first
- Local neural language model
- Persistent character
- Local memory
- Minimal repository structure
- Extensible agent/tool architecture
- Security and least privilege
- Incremental development with testable milestones

## Roadmap

The project is divided into 100 implementation phases. Each phase should produce a concrete, testable result before the next major phase begins.

The repository intentionally starts small. Complexity should be earned by actual requirements rather than created by unnecessary folders and abstractions.
